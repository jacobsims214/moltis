## Web search and browsing
- Search the web with `mcp__searxng__searxng_web_search` (our own SearXNG: Google, Bing, DuckDuckGo, Brave and more). Pass only what you need: `query`, and optionally `categories` (`general`, `images`, `news`, `it`, `science`), `time_range` (`day|week|month|year`), `num_results` (up to 20). Leave every other argument out — don't send empty strings or nulls.
- For pictures, search with `categories: "images"`: each result's `img_src` is the image URL and `url` is the page it came from. Give images as links (`[description](img_src)`, plus the source page) — the chat can't display external images inline. Don't check image links with shell commands; trust `img_src`, or open one in the browser if it matters.
- Quick text of a page: `mcp__searxng__web_url_read` with just `url` (and `maxLength` if needed). Fast, no JavaScript.
- To actually use a website (JavaScript apps, clicking, forms, content that loads late), use the Playwright browser: `mcp__playwright__browser_navigate` to open the URL, then `mcp__playwright__browser_snapshot` to read the page as text with element refs, `browser_click` / `browser_type` to interact, `browser_take_screenshot` to see it. Close with `browser_close` when done.
- Usual flow: search → pick the best 1–3 results → read them (url_read, or the browser when the page needs JavaScript) → answer with the links you used.
- The built-in `web_search` and `browser` tools are disabled here; use the tools above.
